## 0. 当前结论（先看这里）

本轮已经完成四条最小成本生死门。结论是：**固定完美 CSI 下，条件图协商机制有明显收益，但没有任何证据表明 GAT 比物理消息或 MLP 更有价值。** 因此停止继续修改会议版 GAT 骨架，也停止训练残差 GAT和优先级 GAT。

值得保留的新算法骨架是：从 Pure 动作出发，当前活跃接收链路传播其物理 MWS 影响，各链路计算精确加入/退出边际；每轮按边际选冲突邻域局部极大值并行翻转，两轮结束。N=20 静态快照中，它平均比 Pure 高 `15.23%`。

这条算法目前仍是候选而不是最终模型：尚未测试动态队列和 N=50，也尚未整理成严格分布式消息公式。AI贡献若要成立，下一步只能来自**物理公式无法知道的信息**，例如过时、量化或局部 CSI 下真实条件边际的预测；不能再声称完美 CSI 下 GAT提高调度效用。

## 1. 统一状态和目标

当前二元调度集合记为 `a`，链路队列为 `Q`，信道状态为 `H`。唯一性能目标是当前时隙的

```text
U(a; Q, H) = sum_i Q_i R_i(a, H).
```

这里 `R_i` 使用项目中已有的真实 SINR 速率公式。训练标签、局部指标和最终评价不能换成另一个代理目标。

所谓“条件决策”是：链路 `i` 是否发送，必须以其他链路当前动作 `a_-i` 为条件。打开和关闭链路 `i` 的真实效用差为

```text
Delta_i = U(a_i=1, a_-i) - U(a_i=0, a_-i).
```

Gibbs 条件概率为

```text
P(a_i=1 | a_-i, Q, H) = sigmoid(beta * Delta_i).
```

它不是模仿某个 greedy 教师动作；它直接由 MWS 目标定义。

## 2. 阶段 A：零训练机制生死门

正式入口：`experiments/diagnose_conditional_negotiation_gate.py`

固定设置：N=20、10 dBm、Rician K=5 dB、12 张图、三种队列快照。起点统一为 PurePhysicalReuse 的最终动作。

同时检查三种机制：

1. **正收益单链路翻转**：逐条检查加入或退出，只接受使全局 `sum(QR)` 上升的动作。
2. **Gibbs 条件采样**：允许以较小概率暂时走向低收益状态，检查能否离开单链路局部最优。
3. **联合替换**：一个挑战链路加入，同时让其冲突邻域内当前活跃链路退出；这是“GAT 提出联合动作”的备用方向上限。

本阶段故意使用全局信息，因此三者都不是可部署算法。问题只有一个：**这种机制即使拥有完美信息，是否还有至少 2% 的稳定增益？**

停止规则：

- Gibbs 平均增益低于 2%，或超过 20% 的快照受损：停止把 Gibbs 当作主路线。
- 两轮联合替换平均增益低于 2%，或胜率低于 70%：停止联合提案路线。
- 不因为结果接近门槛而修改温度、bias 或增加辅助损失。

## 3. 阶段 B：局部信息损失测试

只对通过阶段 A 的机制进行。

将精确全局 `Delta_i` 换成一跳物理边际 `Delta_i_local`，保持相同更新过程。该实验区分：

- 机制本身无效；
- 机制有效，但有限邻域缺少必要信息。

如果纯局部版本已经保留大部分上限，则 GAT 没有必要，论文应诚实采用物理协商；如果局部版本明显损失，而缺失部分可由有限轮消息概括，才进入阶段 C。

## 4. 阶段 C：最小残差 GAT

GAT 只学习一个量：

```text
epsilon_i = Delta_i_global - Delta_i_local.
```

最终条件分数为 `Delta_i_local + epsilon_i_GAT`。输入仅包含当前动作、相对队列、当前速率、局部边际及有向物理干扰边；不增加静态骨架头、教师动作头或额外融合模块。

必须同时训练一个使用相同节点输入但不交换图消息的 MLP。只有 GAT 显著超过 MLP，才能说明收益来自图结构，而不是参数量。

通过要求：

- 相比 Pure 平均 `sum(QR)` 增益不少于 2%；
- 至少 70% 的竞争快照获益；
- GAT 比同输入 MLP 至少高 1%；
- 不通过则停止，不做结构堆叠。

## 5. 阶段 D：动态性和规模

只有阶段 C 通过后才进行。顺序为固定信道动态队列、N=50 静态快照、N=50 动态队列，最后才是不完美 CSI。主要看 backlog、无 deadline 的 packet delay、delivered throughput，以及每时隙 `sum(QR)`。

## 6. 论文路线的三种可能结局

1. **条件 Gibbs + 残差 GAT 通过**：主线写成直接 MWS 驱动的条件图协商；这是最理想结果。
2. **Gibbs 失败但联合提案通过**：GAT 学习用有限轮提出联合交换，物理目标负责验收；作为较稳健的备用方向。
3. **两者均失败**：停止挽救固定 CSI 下的 GAT，把 PurePhysics 作为可靠算法，并将学习价值严格限定到不完美 CSI、信息压缩或复杂度降低；不能继续声称 GAT 提高固定 CSI 调度效用。

## 7. 实验日志

### A0：实现检查

- 目的：建立不训练的统一上限诊断，且不修改冻结模型。
- 改动：新增独立诊断入口；复用现有信道生成、PurePhysicalReuse 和真实 MWS 目标。
- 状态：通过。增量物理效用与项目统一 `mws_objective` 逐快照核对一致。

### A1：零训练正式机制生死门

- 数据：N=20、10 dBm、Rician K=5 dB，12 张图 × 3 类队列，共 36 个快照。
- 状态：首次运行发现新诊断器的动作张量在不同方法之间意外共享，导致方法起点被污染；该轮数值全部作废，没有用于形成结论。
- 修正：动作状态改为深复制，并增加“接受精确正收益翻转后，真实全局效用不得下降”的运行时断言。
- 修复后精确条件翻转：一轮 `+12.20%`，两轮 `+15.79%`，四轮 `+16.61%`；胜率 `91.67%`，负收益率 `0%`。
- 修复后联合替换：两轮 `+7.35%`，但胜率只有 `63.89%`，未通过预设 70% 门槛，停止作为主路线。
- 修复后 Gibbs：四轮平均 `-63.45%`，正式停止。
- 结论：只保留确定性的可撤销条件翻转主线。

### B1：一跳信息损失

- 精确全局两轮更新：`+16.08%`，胜率 `91.67%`，无负收益。
- 一跳两轮更新：`-3.85%`，只有 `19.44%` 快照获益，`72.22%` 受损。
- 一跳逐决策正负号准确率仍为 `96.03%`，但危险假正收益约占全部判断的 `1.63%`，少数错误产生了很大的全局损失。
- 两跳结果与精确全局结果一致；但本批图一跳平均已覆盖 `82.52%` 节点，两跳为 `100%`，因此两跳本质接近全局信息，不能宣称低开销。
- 结论：一跳物理边际不可靠，且缺失量具有清楚含义——大量阈值外弱干扰的累积外部性。进入最小可学习性审计，不直接训练调度器。

### C0：残差是否可学习

- 任务：只在“一跳边际为正”的候选中，预测真实全局边际，重点识别少数危险假正收益。
- 对照：相同节点输入的 MLP、一层 GAT、两层 GAT；均做连续边际回归，不使用类别权重。
- 通过门槛：GAT拒绝至少 50% 危险候选，同时保留至少 90% 安全候选；危险拒绝率还必须比 MLP 高至少 10 个百分点。
- 测试集：273 个一跳正边际候选，其中真实安全 76 个、危险假正收益 197 个。
- MLP：危险拒绝率 `94.92%`，安全保留率 `59.21%`，相关系数 `0.7540`。
- 一层 GAT：危险拒绝率 `92.39%`，安全保留率 `61.84%`，相关系数 `0.7472`。
- 两层 GAT：危险拒绝率 `92.89%`，安全保留率 `61.84%`，相关系数 `0.7551`。
- 结论：GAT未超过相同输入 MLP，且安全机会损失过多；未通过预设门槛，停止残差 GAT 路线，不增加层数或损失项。

### C1：学习式连续干扰稀疏化的消息预算上限

- 动机：残差无法从现有稀疏图可靠推断，改问是否能直接选择少量最重要的物理影响消息。
- 方法：不可部署的 oracle 已经知道每个接收链路对一次翻转的真实效用贡献，只保留绝对值最大的 10%、25%、50% 或 75%。因此它给出任何 learned attention 所需消息量的乐观下界。
- 通过门槛：最多 25% 消息恢复至少 50% 的全局条件更新增益，且受损快照不超过 20%。
- 结果：10%、25%、50% 和 75% oracle 消息均完全复现全局两轮更新的 `+16.08%`，胜率 `91.67%`，无负收益。
- 解释：这不是 GAT 自动找到了重要边。当前效用中，只有正在发送的链路具有非零受损贡献；Pure 起点本来就稀疏，因此每次翻转只需候选自身和当前活跃接收链路的物理影响消息。
- 结论：不用让 GAT学习边选择。精确条件边际可以写成活跃集合上的稀疏物理消息传递。新的瓶颈是如何把逐链路串行翻转变成固定轮并行更新。

### C2：并行更新优先级是否值得学习

- 方法：每轮先得到所有链路的精确正边际提案，再比较按边际选冲突局部极大值、随机优先级，以及集中式从 8 次随机优先级中挑最好的结果。
- 目的：如果不同优先级带来至少 2% 的稳定差距，GAT可学习状态相关的并行更新优先级；如果按物理边际已经最好或随机上限不稳定，则不训练。
- 两轮串行精确参考：`+16.08%`，胜率 `91.67%`，无负收益。
- 两轮按精确边际选冲突局部极大值并行更新：`+15.23%`，胜率 `88.89%`，负收益率 `2.78%`。
- 随机优先级平均：`+12.73%`；从 8 次随机结果中集中式挑最好：`+15.53%`。
- 最优随机库相对物理边际排序只多 `0.29` 个百分点，远低于 2% 学习门槛。
- 结论：物理边际本身已经是很强的并行优先级，可学习空间太小；停止 GAT并行协调路线。

## 8. 本轮之后的研究决策

### 保留：Active-Set Conditional Physical Message Passing（暂定描述名）

它不是新的 GAT版本，而是本轮发现的候选物理调度器：

1. PurePhysicalReuse 提供非空初始集合；
2. 当前活跃接收链路传播计算条件边际所需的队列、当前速率和干扰敏感度；
3. 每条候选链路计算自己加入或退出后的 MWS 边际；
4. 正边际候选按边际值在冲突邻域内竞争；
5. 局部极大值并行翻转，固定执行两轮。

当前静态 N=20 上限结果是 `+15.23%`，但仍需验证：计算是否能严格写成分布式消息、并行翻转唯一受损快照的原因、动态队列稳定性、N=50 复杂度与性能。

### 停止：固定完美 CSI 下强行寻找 GAT收益

已经停止的具体接口包括静态骨架融合、Gibbs随机采样、局部残差预测和并行优先级学习。它们分别因为目标错位、组合熵过大、GAT不优于MLP、可学习上限过小而停止。不能通过增加层数、温度、类别权重或辅助损失重新开启。

### AI贡献仍然科学成立的唯一近期入口

在不完美 CSI 下，物理模块只能计算“基于观测 CSI 的条件边际”，而真实当前信道下的边际未知。此时可令 GAT学习：

```text
真实条件边际 - 基于过时/量化/局部 CSI 的物理条件边际。
```

这个目标与本轮失败的固定 CSI 残差不同：缺失量来自真实不可观测的信道，而不是让 GAT猜一个物理公式已经知道的量。模型是否值得训练仍必须先做 oracle headroom：若完美边际相对观测边际没有明显动态收益，直接停止。

## 9. 固定 CSI 候选算法的完整定义

### 9.1 当前活动集合与MWS目标

第 `k` 轮二元动作记为 `a^(k)`，活动链路集合为 `A^(k)={i | a_i^(k)=1}`。令 `S_i` 为链路 `i` 的接收信号功率，`G_{j,i}` 为发送链路 `j` 对接收链路 `i` 造成的干扰功率，则

```text
D_i(A) = noise + sum_{j in A, j != i} G_{j,i},
R_i(A) = B log2(1 + S_i / (Gamma D_i(A))),
U(A)   = sum_{i in A} Q_i R_i(A).
```

### 9.2 加入和退出的精确条件边际

若链路 `i` 当前未发送，其加入收益为

```text
Delta_i^+(A)
 = Q_i R_i(A union {i})
 + sum_{j in A} Q_j [R_j(A union {i}) - R_j(A)].
```

第一项是链路 `i` 自己获得的服务，第二项是它对当前活动链路造成的速率损失。若链路 `i` 当前正在发送，其退出收益为

```text
Delta_i^-(A)
 = -Q_i R_i(A)
 + sum_{j in A without i} Q_j [R_j(A without i) - R_j(A)].
```

因此模型同时允许加入和退出，不会像anchor-join一样只能不断增加链路。

### 9.3 为什么它是物理图消息传递

对未活动候选 `i`，每个当前活动接收链路 `j` 可以形成消息

```text
m_{j->i}^+ = Q_j [R_j(D_j + G_{i,j}) - R_j(D_j)].
```

候选链路聚合活动集合消息后得到

```text
Delta_i^+ = Q_i R_i(A union {i}) + sum_{j in A} m_{j->i}^+.
```

退出消息同理，只需将 `D_j+G_{i,j}` 换成 `D_j-G_{i,j}`。所以消息函数、求和聚合和节点更新都能写成MPNN形式：

```text
message   m_{j->i} = phi(Q_j, S_j, D_j, G_{i,j}, a_i, a_j),
aggregate M_i      = sum_j m_{j->i},
update    Delta_i  = psi(Q_i, S_i, D_i, a_i, M_i).
```

但这里的 `phi` 和 `psi` 是物理公式，没有可训练参数。严谨名称应当是**physics-informed graph message passing scheduler**或“MPNN-style graph algorithm”，不能把它直接冒充成学习型MPNN。若未来CSI模块用GAT预测未知边际残差，二者才共同构成physics-informed learned MPNN。

### 9.4 固定两轮并行翻转

每轮形成正边际候选集合

```text
P^(k) = {i | Q_i > 0 and Delta_i^(k) > 0}.
```

候选在硬冲突邻域内比较条件边际，局部最大者同时翻转：

```text
S^(k) = {i in P^(k) | Delta_i^(k)大于所有候选邻居},
a_i^(k+1) = a_i^(k) XOR 1{i in S^(k)}.
```

当前版本固定执行两轮。第一轮纠正Pure中明显不合理的链路，第二轮在新集合条件下重新计算并修正。继续增加到四轮只有很小收益，因此暂不增加轮数。

## 10. 与Zhao 2022中LGS的关系

Zhao论文的LGS是分布式算法，不是集中式上界。其输入是无向硬冲突图和节点效用 `u_i=Q_i r_i`。每轮剩余节点与硬冲突邻居比较固定效用，局部最大者进入调度集合，其邻居永久淘汰，直到形成极大独立集。

| 对比项 | Zhao式LGS | 当前条件物理消息传递 |
|---|---|---|
| 干扰模型 | 无向二元硬冲突 | 连续、可非对称物理干扰 |
| 并发规则 | 有边绝不并发 | 弱干扰链路允许并发 |
| 节点分数 | 固定 `Q_i C_i^solo` | 随活动集合更新的全网MWS边际 |
| 动作演化 | 胜者加入、邻居永久淘汰 | 活动和非活动链路都可翻转 |
| 轮数 | 重复直到剩余集合为空 | 固定两轮 |
| 优化对象 | 硬冲突图上的近似MWIS | 真实SINR下的 `sum Q_i R_i` |

公平适配时，LGS在本项目冲突图上使用 `Q_i C_i^solo`，所有最终动作仍由相同真实SINR公式评价。该实验是把LGS接入我们的物理场景，不是复现Zhao论文的ER随机图结果。
